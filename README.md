# course-testing

Test sandbox for the 2026-2027 edition of the UvA MSc course *Near-term Quantum Computing* (5394NTQC3Y).

This repository is for trying out infrastructure before the real course release: opening tutorial notebooks in Colab from GitHub, notebook-level settings (such as hiding Colab's generative AI features), and publishing lecture notes with GitHub Pages.

Nothing here is course material, and nothing here is final. The course release will live in a separate repository.
