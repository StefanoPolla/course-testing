# course-testing

Test sandbox for the 2026-2027 edition of the UvA MSc course *Near-term Quantum Computing* (5394NTQC3Y).

This repository is for trying out infrastructure before the real course release: opening tutorial notebooks in Colab from GitHub, and publishing lecture notes with GitHub Pages.

Nothing here is course material, and nothing here is final. The course release will live in a separate repository.

## Layout

- [tutorials/](tutorials/): test copies of the tutorial notebooks (student versions), with Open-in-Colab links.
- [notes/](notes/): test lecture notes built with Quarto (website + PDF), with deployment instructions for GitHub Pages.
- [.github/workflows/publish-notes.yml](.github/workflows/publish-notes.yml): manual workflow that builds and publishes the notes.
